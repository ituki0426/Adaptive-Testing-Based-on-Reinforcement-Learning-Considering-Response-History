# EXP017: DQN with Posterior Variance State（EAP求積）

## 目的

EXP007 との差は **強化学習の状態表現** のみ。

EXP007 では状態 = `[θ̂]`（MLE による点推定のみ）だったが、EXP017 では状態 = `[θ̂_EAP, post_var_EAP]` とし、推定の不確実性（事後分散）を DQN の入力に加える。

## EXP007 との変更点

| 変更内容 | EXP007 | EXP017 |
|---|---|---|
| 状態の次元 | 1（θ̂ のみ） | 2（θ̂ + 事後分散） |
| θ推定方法 | MLE + 端点ヒューリスティック | EAP（Gauss-Legendre 求積） |
| 全正解/全不正解の処理 | 端点ヒューリスティック | EAP で自然に解決（事前分布が正則化） |
| ネットワーク入力サイズ | 1 | 2 |

## 状態の定義

- **初期状態**: `[Uniform(-0.5, 0.5), 1.0]`
  - 第1要素: θ の初期推定値（ランダム）
  - 第2要素: 事後分散の初期値 = 事前分散（N(0,1) の分散 = 1.0）
- **逐次更新**: 出題ステップ i 後に `EAP_quadrature(使用済み項目, 回答履歴)` を呼び `[θ̂_EAP, Var(θ|x)]` に更新

## EAP 求積の設定

| パラメータ | 値 |
|---|---|
| 求積点数 (`n_quad`) | 61 |
| θ の範囲 | [-4, +4] |
| 事前分布 | N(0, 1) |

## ネットワーク構造

EXP007 と同じ（入力次元のみ変更）。

| 層 | ユニット数 |
|---|---|
| 入力層 | 2 |
| 第1隠れ層 | 50 |
| 第2隠れ層 | 30 |
| 出力層 | 500（項目数） |

## 使用バンク

`data/uncorrelated_banks/`（500項目、分散値に `sqrt` を取らずに生成）

EXP007 と同じバンクを使用し、状態変更の効果のみを比較する。

## 速度上の注意

EAP 求積はバリデーション・テストループで受検者ごとに逐次計算するため、EXP007 の MLE_TEST より遅い。

- `validation_size=200`、`test_length=40` の場合: 1バリデーション当たり約 200×40 = 8,000 回の EAP 計算
- GPU 学習本体は速いが EAP は CPU 側の計算のため、Colab GPU 環境でもバリデーション部分はやや遅くなる

必要であれば `n_quad` を小さくする（例: 41）か `validation_size` を減らすことで高速化できる。
