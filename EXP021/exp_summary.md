# EXP021: DQN with Log-Transformed Posterior Variance State（EXP017 の正規化改善版）

## 目的

EXP017 との差は **事後分散の入力表現のみ**。

EXP017 では状態 = `[θ̂_EAP, eap_var]` と生の分散値を入力していたが、EXP021 では状態 = `[θ̂_EAP, log(eap_var)]` と log 変換して入力する。

## 背景

EXP017 で事後分散を加えても EXP007（MLE ベースライン）に対する改善が限定的だった原因の一つとして、2次元の入力スケールの不均一が疑われた。

| 次元 | EXP017 の範囲 | EXP021 の範囲 |
|---|---|---|
| `θ̂_EAP` | 約 `[-4, +4]` | 約 `[-4, +4]`（変更なし） |
| `eap_var` | `1.0 → ~0.01`（常に正・単調減少） | `log(1.0)=0.0 → log(0.01)=-4.6`（負方向に変動） |

log 変換により：
- 初期値が `log(1.0) = 0.0` と θ̂ の初期値と同オーダーになる
- `eap_var` の単調減少が線形に近い変化として表現される
- θ̂ と同様に負の値も取るため、ネットワークが両次元を対称的に扱いやすくなる

## EXP017 との変更点

| 変更内容 | EXP017 | EXP021 |
|---|---|---|
| 状態の第2要素 | `eap_var`（生値） | `log(eap_var)` |
| 初期状態の第2要素 | `prior_std² = 1.0` | `log(prior_std²) = 0.0` |
| log のクリップ | なし | `max(eap_var, 1e-10)` で下限保護 |

## 実験条件（EXP017 から変更なし）

| パラメータ | 値 |
|---|---|
| 状態次元 | 2 |
| θ推定方法 | EAP（Gauss-Legendre 求積、n_quad=61） |
| 事前分布 | N(0, 1) |
| 隠れ層 | 100 → 50 |
| gamma | 0.1 |
| training_size | 1000 |

## 使用バンク

`data/uncorrelated_banks/`（500項目、分散値に `sqrt` を取らずに生成）

EXP017/EXP020 と同じバンクを使用し、正規化変更の効果のみを比較する。
