# EXP009: DQN on 3PL Item Banks

## 目的

EXP007（`data/uncorrelated_banks/`、200項目）の DQN 実験を、`data/3PL/`（500項目）のアイテムバンクで再実施する。元論文準拠のバンク設定が MFI・DQN の RMSE に与える影響を検証する。

## EXP007 からの変更点

| 項目 | EXP007 | EXP009 |
|---|---|---|
| バンクディレクトリ | `data/uncorrelated_banks/` | `data/3PL/` |
| バンクファイル名 | `item_bank_{type}_{id}.csv` | `item_bank_uncor_{id}.csv` |
| 項目数（`n_items`） | 200 | 500 |
| `Config.bank_type` | あり（`"uncor"` / `"cor"`） | 削除（3PL は uncor 固定） |
| 出力ファイルの stem | `{type}_{id}_DQN_...` | `3pl_{id}_DQN_...` |
| モデル保存名 | `dqn_{prior}_{type}_{id}_...` | `dqn_{prior}_3pl_{id}_...` |

TD ターゲットの計算方法は EXP007 と同一（出題済み項目のマスクなし）。マスク修正は EXP010 で実施。

## アイテムバンク生成

`src/generate_item_banks_3pl.R` により生成。Wang et al. (2024) の設定に準拠：

- a ~ N(1.2, 0.25)（正値にトランケート）
- b ~ N(0, 1)
- c ~ N(0.25, 0.02)（0 < c < 1 にトランケート）
- 10 バンク × 各 500 項目、シード：20260429

## シミュレーション設定

EXP007 と同一：

- 受検者数：5,000 名、θ ~ N(0, 1)
- テスト長：40 問
- 特性値推定：MLE、範囲 [-4, 4]
- 初期特性値：Uniform(-0.5, 0.5)
- prior = "normal"
- 実施した γ：0.1、0.3、0.6（bank_id=1）、0.1、0.3（bank_id=2）

## 出力

- `EXP009/models/dqn_normal_3pl_{bank_id}_gamma_{gamma}.pt` — 学習済みモデル
- `EXP009/results/summary_3pl_{bank_id}_DQN_normal_gamma_{gamma}.csv` — ステップ別 Bias・RMSE・MAE
- `EXP009/results/rmse_comparison_3pl_{bank_id}_gamma_{gamma}.png` — MFI vs DQN の RMSE 推移プロット

## 考察

**MFI の再現性**：3PL バンク（500項目）を使用したことで MFI の RMSE が元論文値に大幅に近づいた。step 40 では 0.240〜0.245 と元論文の 0.245 にほぼ一致する。序盤（step 10）では 0.504〜0.522 と元論文の 0.493 をやや上回る傾向が残る。

**DQN の性能**：全 γ・全 bank_id を通じて step 40 の DQN RMSE は 0.282〜0.300 であり、MFI（0.240〜0.245）を下回れていない。元論文では DQN が MFI を上回る（0.227 < 0.245）が、EXP009 では逆転は生じていない。γ=0.1 が最も RMSE が低く、γ が大きいほど性能が落ちる傾向がある。

**EXP009 の限界**：TD ターゲット計算に出題済み項目のマスクがない（EXP007 と同一）。この修正を加えた EXP010 の結果と比較することで、マスクの効果が評価できる。
